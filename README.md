# CursorRemote

Чат с агентом Cursor IDE с Android **через интернет** — без установки Cursor на телефон.

Кофейня, диван, электричка: пишешь задачу с телефона, агент работает на твоём ПК.

📢 Канал: https://t.me/CursorRemote  
📋 Условия и возврат: [LEGAL.md](LEGAL.md)

## Для кого это

- Cursor крутится на ПК, а ты — не за столом.
- Нужно дать агенту задачу по проекту с телефона.
- Не хочется поднимать AnyDesk ради одного чата с IDE.

Коротко: код подключения → список проектов → чат с агентом → ответ на телефоне.

## Быстрый старт

### 1. ПК

1. Скачайте `CursorRemoteAgent.exe` из [Releases](https://github.com/thekingoffamily/CursorRemote/releases).
2. Запустите — только иконка в трее.
3. ПКМ → **Скопировать код подключения** (`CR-XXXX-XXXX:ключ`).

### 2. Телефон

1. Установите CursorRemote (RuStore / APK).
2. Вставьте полный код из трея.
3. Кнопка **«Ключ Cursor»** — вставьте API Key с [cursor.com](https://cursor.com) (Dashboard → Integrations). Зелёный кружок = ключ на ПК принят.
4. Откройте проект → пишите агенту. Для SSH при запросе — пароль через иконку ключа в чате.
