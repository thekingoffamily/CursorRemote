## Для кого это

- Для тех, у кого Cursor крутится на мощном ПК, а жизнь — в телефоне.
- Для «ой, баг в проде» в 23:40, когда ноут уже в сумке у двери.
- Для тех, кому AnyDesk ради одной IDE — как экскаватор вместо ложки.

Коротко: карточки проектов на Android → тап → правишь код через чат с аггентом на своём Cursor IDE.

## 🚀 Быстрый старт

### 1️⃣ ПК (Local Agent для Windows)

1. Скачайте `CursorRemoteAgent.exe` из [Releases](https://github.com/thekingoffamily/CursorRemote/releases):  
   👉 https://github.com/thekingoffamily/CursorRemote
2. Запустите — окна не будет, только иконка в трее.
3. ПКМ по иконке → **Скопировать код подключения** (`CR-XXXX-XXXX:ключ`).  
   Одного ID без ключа недостаточно — так чужой не подцепится к твоей лицензии.

### 2️⃣ Телефон

1. Установите CursorRemote из RuStore (ссылка появится позже).
2. Вставьте **полный код** (ID:ключ) из трея.
3. Карточки проектов → тап → пиши агенту.
